
# License Plate Detection — Computer Vision Project

## Overview
A team-based Computer Vision project focused on
license plate detection using object detection techniques.

## Dataset
- Name: License Plate Recognition v12
- Source: [Roboflow Universe](https://universe.roboflow.com/roboflow-universe-projects/license-plate-recognition-rxg4e)
- Format: Pascal VOC XML
- Images: 10,125 (as reported by the original export)
- Classes: License_Plate

See [DATASET_LICENSE.txt](DATASET_LICENSE.txt)
for dataset attribution and licensing information.

## Project Objectives
1. Analyze and validate the dataset.
2. Investigate possible data leakage.
3. Establish a baseline object detection model.
4. Implement an improvement over the baseline.
5. Evaluate and compare model performance.

## Project Structure
- README.md: Project documentation
- DATASET_LICENSE.txt: Dataset attribution and license
- requirements.txt: Python dependencies
- .gitignore: Files excluded from Git
